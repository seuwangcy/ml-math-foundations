# Notes

This is where the actual notes live.

## How a note is structured

Every note answers the same five questions:

1. **What problem does this answer?**
   The question in plain words — what confusion does this clear up?

2. **Intuition**
   The picture in your head *before* the formulas. If you can't draw it, you
   don't get it yet.

3. **Formal definition / derivation**
   The math. Worked carefully, with every step justified.

4. **Where it shows up in ML**
   A concrete ML algorithm or paper that uses this idea. The goal: when you
   meet it in the wild, you recognize it.

5. **Connections**
   What other notes link to this one? What's a natural next read?

## Naming convention

Files are named in kebab-case, in plain English:

```
notes/
├── why-negative-gradient-is-steepest-descent.md
├── pca-geometric-meaning.md
├── cross-entropy-vs-mse.md
└── ...
```

The filename is the *question*, not the *answer*. That way the note reads as a
small investigation, not a textbook entry.

## Drafts

Notes start as drafts. Expect:
- Typos
- Hand-wavy arguments
- Missing references
- Dead ends

A note graduates to "first complete pass" when the five sections are filled in
and the derivation has no gaps I can spot.
